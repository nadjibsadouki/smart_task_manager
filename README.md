# Smart Task Manager

Smart Task Manager est une application web moderne pour organiser les tâches, gérer les priorités, suivre les échéances et améliorer la productivité.

## Fonctionnalités

- Gestion des tâches
- Priorités : faible, moyenne, haute
- Suivi des tâches terminées et à faire
- Page d’analyses
- Assistant IA simulé
- Focus mode
- Page connexion / inscription

## Technologies utilisées

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub

## Pages du projet

- Accueil
- Tâches
- Analyses
- IA
- Focus
- Authentification
